# フロントエンド共通デザインガイドライン & API データ連携仕様

このドキュメントは、フロントエンドのデザイン定義（カラーシステム・アクセシビリティ配慮）およびバックエンドとのデータ連携仕様をまとめたものです。

---

## 🎨 1. CSS 共通カラー定義 (色覚配慮 & 絵本トーン)

`app/globals.css` の `:root` に設定する基本カラーパレットです。

### 🎨 CSS 変数定義 (`globals.css`)

```css
:root {
  /* 1. ベースカラー（背景：真っ白を避けた、目にやさしい紙・アイボリー調） */
  --color-bg-base: #fafaf9;          /* Tailwind: stone-50 相当 */
  --color-bg-surface: #ffffff;       /* カードや枠の内側 */

  /* 2. メインカラー（操作系：視認性が高く、色覚に依存しにくい落ち着いた青） */
  --color-primary: #0284c7;          /* Tailwind: sky-600 相当 */
  --color-primary-hover: #0369a1;    /* ボタンホバー時: sky-700 相当 */
  --color-primary-text: #ffffff;     /* ボタン内の文字色 */

  /* 3. アクセント / ハイライト（重要単語：色覚特性でも見えやすく、文字がつぶれない淡い黄色） */
  --color-highlight-bg: #fef3c7;     /* 単語背景: amber-100 相当 */
  --color-highlight-border: #f59e0b; /* 単語の下線: amber-500 相当（下線で形でも認識させる） */
  --color-highlight-text: #1c1917;   /* 単語文字色: stone-900 相当（コントラスト比を確保） */

  /* 4. 基本テキスト・枠線（真っ黒を避けた温かみのあるチャコール） */
  --color-text-main: #292524;        /* 本文文字色: stone-800 相当 */
  --color-text-sub: #78716c;         /* 補足文字色: stone-500 相当 */
  --color-border: #e7e5e4;           /* 枠線: stone-200 相当 */
}
```

### 💡 デザイン意図・解説
- **背景（ベース）**: 紙のようなやさしい質感 (`#fafaf9`)
- **メイン（ボタン・タブ）**: 色覚特性に影響されにくい青 (`#0284c7`)
- **アクセント（単語ハイライト）**: 薄い黄色の背景 (`#fef3c7`) だけでなく、**下線（アンダーライン `#f59e0b`）もセットで引くルール**とすることで、色覚特性に配慮した設計にしています。
- **本文テキスト**: 目に優しいチャコールカラー (`#292524`)

## 🔄 3. バックエンド共有データ連携仕様

### 1️⃣ 単語登録画面 

#### 1. 翻訳候補の取得（英単語を送って日本語候補をもらう）
英単語を入力後、「翻訳を取得」ボタンを押したときの通信です。

- **リクエスト (Request)**: 英語文字列の配列
  ```json
  [
    "apple",
    "banana"
  ]
  ```
- **レスポンス (Response)**: 単語ごとの日本語訳候補
  ```json
  [
    {
      "english": "apple",
      "translations": ["りんご", "リンゴの木"]
    },
    {
      "english": "banana",
      "translations": ["バナナ", "甘味果実"]
    }
  ]
  ```

#### 2. 単語の登録（選択した日本語訳とユーザーIDを保存）
プルダウンで日本語を選び終え、「この単語で登録する」を押したときの通信です。

- **リクエスト (Request)**: `user_id` を含むオブジェクト配列
  ```json
  [
    {
      "user_id": 1,
      "english": "apple",
      "japanese": "りんご"
    },
    {
      "user_id": 1,
      "english": "banana",
      "japanese": "バナナ"
    }
  ]
  ```
- **レスポンス (Response)**: 登録可否のメッセージ
  ```json
  {
    "success": true,
    "message": "registered successfully"
  }
  ```
