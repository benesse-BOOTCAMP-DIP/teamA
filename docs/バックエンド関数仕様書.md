# バックエンド関数仕様書

本ドキュメントでは、単語帳アプリ（word-to-text-anki）で利用するバックエンド関数の引数および返却するJSONデータの仕様について定義します。

---

## 1. 関数仕様一覧

### ① 和訳取得関数 (`fetchMeanings`)

指定された英単語のリストから、外部API（英和辞書など）を参照してそれぞれの訳のリストを返します。

#### 引数 (Request JSON)
```json
{
  "words": ["Apple", "Banana"]
}
```
- `words` *(array[string], 必須)*: 検索対象の英単語・熟語の配列

#### 返却値 (Response JSON)
**成功時:**
```json

{
  "success": true,
  "translations": [
    {
      "word": "Apple",
      "meanings": ["りんご", "アップル"]
    },
    {
      "word": "Banana",
      "meanings": ["バナナ"]
    }
  ]
}
```

**失敗時:**
```json
{
  "success": false,
  "error": "和訳データの取得に失敗しました"
}
```

---

### ② 単語登録関数 (`addWords`)

指定したユーザーID（`userId`）に紐づけて、英単語と意味を複数一括で登録します。

#### 引数 (Request JSON)
```json
{
  "userId": 1,
  "words": [
    {
      "word": "Apple",
      "meaning": "りんご"
    },
    {
      "word": "Banana",
      "meaning": "バナナ"
    }
  ]
}
```
- `userId` *(int4, 必須)*: ユーザーID
- `words` *(array, 必須)*: 登録する単語データの配列
  - `word` *(string, 必須)*: 英単語・熟語
  - `meaning` *(string, 必須)*: 意味・定義

#### 返却値 (Response JSON)
**成功時:**
```json
{
  "success": true
}
```

**失敗時:**
```json
{
  "success": false,
  "error": "登録に失敗しました"
}
```

---

### ③ 単語削除関数 (`deleteUserMeaning`)

指定したユーザーID（`userId`）および意味ID（`meaningId`）に対応する `user_meaning` のレコードを削除します。

#### 引数 (Request JSON)
```json
{
  "userId": 1,
  "meaningId": 1
}
```
- `userId` *(int4, 必須)*: ユーザーID
- `meaningId` *(int4, 必須)*: 削除対象の意味ID (`meaning_id`)

#### 返却値 (Response JSON)
**成功時:**
```json
{
  "success": true
}
```

**失敗時:**
```json
{
  "success": false,
  "error": "削除対象のレコードが見つかりません"
}
```

---

### ④ 単語一覧取得関数 (`getWords`)

指定したユーザーIDに紐づく登録済み単語の一覧を取得します。

#### 引数 (Request JSON)
```json
{
  "userId": 1
}
```
- `userId` *(int4, 必須)*: ユーザーID

#### 返却値 (Response JSON)
**成功時 (配列データ):**
```json
[
  {
    "meaning_id": 1,
    "word": "Apple",
    "meaning": "りんご",
    "created_at": "2026-09-01T00:00:00Z",
    "updated_at": "2026-09-01T00:00:00Z"
  },
  {
    "meaning_id": 2,
    "word": "Banana",
    "meaning": "バナナ",
    "created_at": "2026-09-02T00:00:00Z",
    "updated_at": "2026-09-02T00:00:00Z"
  }
]
```
