## 1. 単語登録 API

ユーザーが確定した英単語と日本語訳のペアをデータベースに保存します。

- **URL**: `POST /api/words`
- **Content-Type**: `application/json`

### 📥 リクエスト（フロント → バック）

```json
{
  "userId": 1,
  "words": [
    { "english": "spring", "japanese": "春" },
    { "english": "apple", "japanese": "りんご" }
  ]
}
```

| フィールド         | 型            | 必須 | 説明                          |
| ------------------ | ------------- | ---- | ----------------------------- |
| `userId`           | `number`      | ○    | 登録するユーザーのID          |
| `words`            | `WordInput[]` | ○    | 登録する単語の配列（1件以上） |
| `words[].english`  | `string`      | ○    | 英単語（1〜45文字）           |
| `words[].japanese` | `string`      | ○    | 日本語訳（1〜45文字）         |

> ℹ️ `userId` はログイン機能ができるまで一旦 `1` を送ってください。

### 📤 レスポンス（バック → フロント）

#### 成功時 `200 OK`

保存された単語のID（`meaning_id`, `word_id`）を含んだ配列が返ります。

```json
{
  "success": true,
  "data": [
    {
      "meaning_id": 8,
      "word_id": 6,
      "english": "spring",
      "japanese": "春"
    },
    {
      "meaning_id": 9,
      "word_id": 7,
      "english": "apple",
      "japanese": "りんご"
    }
  ]
}
```

#### 失敗時 `400 Bad Request`

文字数上限（45文字）や空文字などのバリデーションエラーがある場合、エラーメッセージが返ります。

```json
{
  "success": false,
  "error": "英単語は45文字以内で入力してください"
}
```

| ケース               | `error` の例                             |
| -------------------- | ---------------------------------------- |
| 英単語が空           | `英単語を入力してください`               |
| 英単語が46文字以上   | `英単語は45文字以内で入力してください`   |
| 日本語訳が空         | `日本語訳を入力してください`             |
| 日本語訳が46文字以上 | `日本語訳は45文字以内で入力してください` |

### 型定義

```ts
export interface WordInput {
  english: string;
  japanese: string;
}

export interface RegisterWordsRequest {
  userId: number;
  words: WordInput[];
}
```
