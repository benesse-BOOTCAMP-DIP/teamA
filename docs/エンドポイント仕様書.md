## 1. 単語登録 API

ユーザーが確定した英単語と日本語訳のペアをデータベースに保存します。

- **URL**: `POST /api/words`
- **Content-Type**: `application/json`

### 📥 リクエスト（フロント → バック）

```json
{
  "userId": 1,
  "words": [
    { "english": "spring", "japanese": "春" },
    { "english": "apple", "japanese": "りんご" }
  ]
}
```

| フィールド         | 型            | 必須 | 説明                          |
| ------------------ | ------------- | ---- | ----------------------------- |
| `userId`           | `number`      | ○    | 登録するユーザーのID          |
| `words`            | `WordInput[]` | ○    | 登録する単語の配列（1件以上） |
| `words[].english`  | `string`      | ○    | 英単語（1〜45文字）           |
| `words[].japanese` | `string`      | ○    | 日本語訳（1〜45文字）         |

> ℹ️ `userId` はログイン機能ができるまで一旦 `1` を送ってください。

### 📤 レスポンス（バック → フロント）

#### 成功時 `200 OK`

保存された単語のID（`meaning_id`, `word_id`）を含んだ配列が返ります。

```json
{
  "success": true,
  "data": [
    {
      "meaning_id": 8,
      "word_id": 6,
      "english": "spring",
      "japanese": "春"
    },
    {
      "meaning_id": 9,
      "word_id": 7,
      "english": "apple",
      "japanese": "りんご"
    }
  ]
}
```

#### 失敗時 `400 Bad Request`

文字数上限（45文字）や空文字などのバリデーションエラーがある場合、エラーメッセージが返ります。

```json
{
  "success": false,
  "error": "英単語は45文字以内で入力してください"
}
```

| ケース               | `error` の例                             |
| -------------------- | ---------------------------------------- |
| 英単語が空           | `英単語を入力してください`               |
| 英単語が46文字以上   | `英単語は45文字以内で入力してください`   |
| 日本語訳が空         | `日本語訳を入力してください`             |
| 日本語訳が46文字以上 | `日本語訳は45文字以内で入力してください` |

### 型定義

```ts
export interface WordInput {
  english: string;
  japanese: string;
}

export interface RegisterWordsRequest {
  userId: number;
  words: WordInput[];
}
```

## 2. 単語一覧取得 API

ログイン中のユーザーが登録した単語一覧（および作成した物語一覧）を取得します。
単語一覧画面や、物語生成時の単語選択画面で使用します。

- **URL**: `GET /api/words`
- **Query Parameters**: `userId` (例: `/api/words?userId=1`)

### 📥 リクエスト（フロント → バック）

| パラメータ | 型       | 必須 | 説明                                                        |
| :--------- | :------- | :--- | :---------------------------------------------------------- |
| `userId`   | `number` | ○    | 取得対象のユーザーID（ログイン機能実装まで一旦 `1` を指定） |

> ℹ️ 例: `fetch('/api/words?userId=1')`

### 📤 レスポンス（バック → フロント）

#### 成功時 `200 OK`

モック API（`/api/mocks/words`）と**完全に同一の形式**で返却されます。
単語・物語ともに**登録日時の新しい順（降順）**でソートされています。
同じ英単語（例: `book`）で複数の意味（「本」「予約する」）が登録されている場合、それぞれ別の `meaning_id` を持ちつつ、同じ `word_id` で返されます。

```json
{
  "stories": [
    {
      "id": 1,
      "title": "A Quick Morning Exercise",
      "content": "In the morning, she decided to run in the park..."
    }
  ],
  "words": [
    {
      "meaning_id": 9,
      "word_id": 7,
      "english": "summer",
      "japanese": "夏"
    },
    {
      "meaning_id": 4,
      "word_id": 1,
      "english": "book",
      "japanese": "予約する"
    },
    {
      "meaning_id": 1,
      "word_id": 1,
      "english": "book",
      "japanese": "本"
    }
  ]
}
```

| フィールド           | 型               | 説明                                                   |
| :------------------- | :--------------- | :----------------------------------------------------- |
| `stories`            | `StoryItem[]`    | そのユーザーが作成した物語の配列（新しい順）           |
| `stories[].id`       | `number`         | 物語ID (`story_id`)                                    |
| `stories[].title`    | `string`         | 物語のタイトル                                         |
| `stories[].content`  | `string`         | 物語の本文 (`story`)                                   |
| `words`              | `WordListItem[]` | そのユーザーが登録した単語の配列（登録日時が新しい順） |
| `words[].meaning_id` | `number`         | 意味ID（`meanings` テーブルの主キー）                  |
| `words[].word_id`    | `number`         | 単語ID（`words` テーブルの主キー）                     |
| `words[].english`    | `string`         | 英単語                                                 |
| `words[].japanese`   | `string`         | 日本語訳                                               |

#### 失敗時 `500 Internal Server Error`

```json
{
  "error": "単語一覧の取得に失敗しました"
}
```

### 型定義

```ts
export interface StoryItem {
  id: number;
  title: string;
  content: string;
}

export interface WordListItem {
  meaning_id: number;
  word_id: number;
  english: string;
  japanese: string;
}

export interface WordsListResponse {
  stories: StoryItem[];
  words: WordListItem[];
}
```
